# 2.2.22 — Menús de programación

Se conserva la laptop y la lógica de proyectos. ISPSoft y DOPSoft separan diseño, comunicación y compilación/transferencia. El editor ofrece insertar/eliminar selección, menú de proyecto con fuentes y ayuda cerrada inicialmente. Controles adaptables al ancho táctil, sin etiquetas de menú inertes. El menú Proyecto se cierra con Escape o al salir su foco.

Validación: npm install (0 vulnerabilidades), check y build; modelo de puesta en marcha; pruebas de laptop a 393 y 1180 px; flujo completo Chromium y WebKit a 393 px (edición, error de compilación, transferencia, marcha/paro, discrepancia de baudios y recuperación).
