# Texturas del terreno de Agro

- `dirt-polyhaven.jpg`: versión reducida de la textura fotográfica **Dirt**, de Charlotte Baglioni, [Poly Haven](https://polyhaven.com/a/dirt), licencia [CC0](https://creativecommons.org/publicdomain/zero/1.0/). La fotografía original representa aproximadamente 2 m de terreno.
- `ground-detail-polyhaven.jpg`: adaptación en escala de grises y aclarada de esa misma imagen. Se mezcla con los colores de cada territorio y se usa tanto en el suelo como en las vías. El mapa de detalle se repite cada 4 m en el suelo y cada 2 m en los caminos; no afecta los datos físicos del terreno.
- `sparse-grass-polyhaven.jpg`: textura fotográfica **Sparse Grass**, de Amal Kumar, [Poly Haven](https://polyhaven.com/a/sparse_grass), licencia CC0. Imagen reducida de un área de unos 2 m, combinada con Dirt para las zonas de vegetación.

El código conserva una textura procedural de respaldo si el archivo local no está disponible.
